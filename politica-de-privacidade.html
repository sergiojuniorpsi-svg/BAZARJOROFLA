Política de Privacidade

Data de Vigência: 19 de Outubro de 2025

Última Atualização: 19 de Outubro de 2025

Conformidade com a LGPD

A BAZAR JOROFLA LTDA está comprometida com a proteção de dados pessoais e atua em conformidade com a Lei Geral de Proteção de Dados (Lei 13.709/2018) e demais legislações aplicáveis.

1. Introdução

A BAZAR JOROFLA LTDA ("nós", "nosso" ou "nossa") valoriza a privacidade e a proteção dos dados pessoais de nossos clientes, colaboradores e visitantes. Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos suas informações pessoais.

Ao utilizar nossos serviços, site ou realizar compras em nossa loja física, você concorda com os termos desta Política de Privacidade.

2. Dados que Coletamos

Coletamos diferentes tipos de dados para melhor atendê-lo:

2.1 Dados Pessoais Identificáveis

  • Informações de Contato: Nome completo, endereço residencial, e-mail, telefone
  • Dados Cadastrais: CPF, RG, data de nascimento
  • Informações de Pagamento: Dados de cartão de crédito/débito (quando aplicável)

2.2 Dados de Compra e Preferências

  • Histórico de Compras: Produtos adquiridos, valores, datas de compra
  • Preferências: Produtos de interesse, categorias favoritas
  • Dados de Entrega: Endereços para envio de produtos

2.3 Dados Técnicos e de Navegação

  • Dados do Dispositivo: Endereço IP, tipo de navegador, sistema operacional
  • Cookies: Informações de navegação no site
  • Dados de Comunicação: E-mails trocados, mensagens via WhatsApp

3. Como Usamos Seus Dados

Utilizamos suas informações pessoais para as seguintes finalidades:

  • Processar e entregar seus pedidos
  • Enviar confirmações de compra e atualizações de pedidos
  • Fornecer suporte ao cliente e responder a consultas
  • Enviar comunicações de marketing (com seu consentimento)
  • Melhorar nossos produtos e serviços
  • Cumprir obrigações legais e regulatórias
  • Prevenir fraudes e garantir a segurança das transações
  • Personalizar sua experiência de compra
  • Enviar newsletters e promoções (quando autorizado)

4. Bases Legais para o Tratamento

De acordo com a LGPD, tratamos dados pessoais com base nas seguintes hipóteses legais:

  • Consentimento: Quando você autoriza expressamente o tratamento
  • Execução de Contrato: Para cumprir obrigações contratuais
  • Obrigação Legal: Para cumprir determinações legais ou regulatórias
  • Legítimo Interesse: Para operar nosso negócio e melhorar serviços

5. Compartilhamento de Dados

Não vendemos seus dados pessoais. Podemos compartilhar informações com:

5.1 Prestadores de Serviços

  • Empresas de Entrega: Para entrega de produtos
  • Processadores de Pagamento: Para processar transações
  • Serviços de Marketing: Para enviar comunicações (com consentimento)
  • Sistemas de Gestão: Para operações comerciais

5.2 Requisitos Legais

  • Autoridades Fiscais: Para cumprimento de obrigações fiscais
  • Órgãos Governamentais: Quando exigido por lei
  • Processos Judiciais: Em resposta a ordens judiciais

6. Segurança dos Dados

Medidas de Segurança Implementadas:

  • Criptografia de dados sensíveis
  • Controles de acesso restritos
  • Monitoramento de sistemas
  • Backups regulares
  • Treinamento de colaboradores em proteção de dados
  • Protocolos de segurança física para documentos

Implementamos medidas técnicas e organizacionais para proteger seus dados contra acesso não autorizado, alteração, divulgação ou destruição.

7. Retenção de Dados

Mantemos seus dados pessoais apenas pelo tempo necessário para:

  • Cumprir as finalidades para as quais foram coletados
  • Atender a requisitos legais e regulatórios
  • Resolver disputas e fazer cumprir acordos
  • Manter registros comerciais adequados

Após o término do prazo de retenção, os dados são eliminados ou anonimizados de forma segura.

8. Seus Direitos sob a LGPD

De acordo com a Lei Geral de Proteção de Dados, você tem os seguintes direitos:

  • Confirmação e Acesso: Confirmar a existência de tratamento e acessar seus dados
  • Correção: Solicitar correção de dados incompletos, inexatos ou desatualizados
  • Anonimização, Bloqueio ou Eliminação: Solicitar anonimização, bloqueio ou eliminação de dados desnecessários ou excessivos
  • Portabilidade: Solicitar a portabilidade dos dados a outro fornecedor de serviço
  • Eliminação: Solicitar a eliminação dos dados tratados com consentimento
  • Informação sobre Compartilhamento: Obter informações sobre entidades com quem compartilhamos dados
  • Revogação do Consentimento: Revogar o consentimento a qualquer momento

Para exercer esses direitos, entre em contato conosco através dos canais indicados abaixo.

9. Cookies e Tecnologias Similares

Nosso site utiliza cookies para melhorar sua experiência de navegação. Cookies são pequenos arquivos de texto armazenados no seu dispositivo. Você pode controlar o uso de cookies através das configurações do seu navegador.

10. Links para Sites de Terceiros

Nosso site pode conter links para sites de terceiros. Esta Política de Privacidade não se aplica a esses sites externos. Recomendamos que você revise as políticas de privacidade de qualquer site que visite.

11. Dados de Crianças e Adolescentes

Não coletamos intencionalmente dados pessoais de crianças menores de 13 anos. Se tomarmos conhecimento de que coletamos dados de uma criança sem verificação do consentimento parental, tomaremos medidas para remover essas informações de nossos sistemas.

12. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Notificaremos sobre mudanças significativas através de nosso site ou por e-mail. A data da última atualização será sempre indicada no início deste documento.
